CSV Diff Lookup

Bandingkan file CSV Lama dan Baru menggunakan prinsip VLOOKUP: gabungkan kolom jadi satu new key, pengecekan, dan setiap baris yang tidak match dengan apapun (#N/A) langsung ditandai sebagai perbedaan.

🔒 Semua proses di browser — file tidak pernah diunggah ke server manapun
1. Pilih dua file
File Lama adalah acuan, file Baru yang dibandingkan terhadapnya.
File Lama (Before)
Klik atau drag and drop file .csv ke sini
File Baru (After)
Klik atau drag and drop file .csv ke sini
2. Dummy Key VLOOKUP
Default: semua kolom digabung jadi satu dummy key (menggunakan prinsip metode manual Excel). Uncheck beberapa kolom jika ingin rubah rincian kolom mana yang berubah pada baris yang diinginkan.
3. Hasil
Dibuat untuk perbandingan cepat antar dua export CSV. You can use it everytime
